# คำถามสำหรับประชุมเตรียมนำร่อง — รพ.สต.แม่อาย

> เอกสารนี้ใช้ประกอบการคุยกับ ผอ.รพ.สต. / พยาบาลวิชาชีพ / ตัวแทน อสม. ก่อนเริ่มพัฒนาระบบ sync (M4)
> คำตอบแต่ละข้อจะใช้ยืนยันหรือแก้การตัดสินใจใน [ADR 0010](adr/0010-offline-hub-spoke-file-sync.md)–[0014](adr/0014-feature-flags-export-and-emergency-call.md) และ [ROADMAP](ROADMAP.md)
> สิ่งที่ควรนำไปด้วย: มือถือ Android ที่ติดตั้ง APK เวอร์ชันข้อมูลสมมติ (flavor `dev` หลัง M2), ตัวอย่าง PDF รายงานผลคัดกรอง

ช่อง **ผลกระทบถ้าคำตอบต่างจากที่สมมติ** บอกว่าต้องเปลี่ยนแผนตรงไหน

## 1. ขั้นตอนการทำงานจริง (สำคัญที่สุด — ถามก่อน)

| # | คำถาม | สมมติฐานตอนนี้ | ผลกระทบถ้าคำตอบต่าง |
|---|---|---|---|
| 1.1 | ปัจจุบัน อสม. คัดกรอง NCD อย่างไร? (กระดาษ / แอปอื่น เช่น Smart อสม. / กรอกเข้า JHCIS ที่ รพ.สต.) | ใช้กระดาษแล้วพยาบาลคีย์เข้าระบบภายหลัง | ถ้ามีแอปของ สธ. อยู่แล้ว ต้องหาจุดที่แอปเราเติมเต็ม ไม่ใช่ทำซ้ำ |
| 1.2 | อสม. 1 คนดูแลกี่หลังคาเรือน / กี่หมู่บ้าน? คัดกรองปีละกี่ครั้ง ช่วงไหน? | 1 อสม. ≈ 10–15 หลังคาเรือน ในหมู่บ้านเดียว | กำหนดขนาดไฟล์ sync และการกำหนดพื้นที่ (VhvAssignment) |
| 1.3 | อสม. กลับมาส่งข้อมูลที่ รพ.สต. บ่อยแค่ไหน? (ทุกวัน / ทุกสัปดาห์ / ประชุม อสม. ประจำเดือน) | อย่างน้อยเดือนละครั้งในการประชุม อสม. | ถ้านานกว่านั้น ต้องรองรับส่งไฟล์ผ่าน LINE จากบ้าน |
| 1.4 | เจาะน้ำตาลปลายนิ้วตอนเช้าก่อนกินข้าว (อดอาหาร) หรือเจาะเวลาใดก็ได้? | มีทั้งสองแบบ | ยืนยันว่าต้องมีช่อง "อดอาหาร 8 ชม.?" และเกณฑ์แยก |
| 1.5 | เมื่อเจอผู้ที่เสี่ยงสูง / ความดันวิกฤต ปัจจุบันแจ้งพยาบาลอย่างไร? (โทร / LINE กลุ่ม) | โทรหรือ LINE กลุ่ม | ออกแบบปุ่ม "แจ้งพยาบาล" ให้เปิด LINE/โทรศัพท์ แทน webhook |
| 1.6 | พยาบาลต้อง "รับรองผล" ทุกรายการ หรือเฉพาะกลุ่มเสี่ยง? | ทุกรายการ แต่ต้องการรับรองเป็นชุด | กำหนดว่าต้องทำ batch approve หรือไม่ |
| 1.7 | เบอร์โทรที่ถูกต้องของ รพ.สต. คือเบอร์ไหน? (ในแอปตอนนี้มี 053-459034 และ 053-459-000 ไม่ตรงกัน) กรณีฉุกเฉินให้โทร 1669 หรือโทรหาพยาบาลก่อน? | 1669 ก่อน แล้วค่อยโทร รพ.สต. | ตั้งค่าปุ่มโทรฉุกเฉิน (ADR 0014) |
| 1.8 | ระหว่างเยี่ยมบ้าน อสม. วางมือถือนานแค่ไหน? ถ้าแอปล็อกเองหลังไม่ได้ใช้ 5 นาทีจะเป็นภาระไหม? | 5 นาทีพอดี | ปรับค่าเวลาล็อก (ADR 0011) |

| 3.2 | ต้องการให้ข้อมูลคัดกรองจากแอปเข้า JHCIS/HOSxP ไหม? หรือแค่ดูในแอปก็พอ? | อยากได้ แต่ไม่ต้องเชื่อมอัตโนมัติ | ถ้าต้องการ → ต้องศึกษาโครงสร้าง 43 แฟ้ม (แฟ้ม NCDSCREEN) |
| 3.3 | มีรายชื่อประชากร/หลังคาเรือนในระบบเดิมที่ส่งออกเป็นไฟล์ได้ไหม? | ส่งออกเป็น Excel ได้ | ถ้าได้ → ทำฟังก์ชันนำเข้ารายชื่อตั้งต้นที่ hub |
| 3.4 | ถ้าจะส่งข้อมูลออกจากแอป ต้องการไฟล์รูปแบบไหน และใครเป็นคนนำเข้า? (Excel / CSV / แฟ้ม NCDSCREEN ของ 43 แฟ้ม) | Excel สำหรับรายงาน | กำหนดการทำ export ใหม่ใน M5 (จะซ่อนไว้ใน M1 ตาม ADR 0014) |

## 4. เกณฑ์ทางการแพทย์ (ให้พยาบาลตรวจ)

| # | คำถาม | สมมติฐานตอนนี้ | ผลกระทบถ้าคำตอบต่าง |
|---|---|---|---|
| 4.1 | เกณฑ์เบาหวาน: FBS ≥126 = สูง, 100–125 = เสี่ยง ถูกต้องตามแนวทางที่ใช้อยู่ไหม? ถ้าเจาะไม่อดอาหารใช้เกณฑ์อะไร? | ตามแนวทางคัดกรอง สธ. | ปรับ `NcdRiskCalculator` หลังประชุม |
| 4.2 | เกณฑ์ความดัน: ≥140/90 = สูง, ≥120/80 = เสี่ยง และค่าวิกฤตที่ต้องแจ้งด่วน (เช่น ≥180/110)? | ตามนี้ | ปรับเกณฑ์และ ClinicalTriageAlert |
| 4.3 | อ้วนลงพุง: ใช้รอบเอว ≥90/80 ซม. หรือ "รอบเอว > ส่วนสูง/2"? ใช้ BMI ≥25 ร่วมไหม? | รอบเอว > ส่วนสูง/2 เป็นหลัก | ปรับเกณฑ์หลังประชุม |
| 4.4 | CVD: ใช้ Thai CV Risk Score แบบไม่ใช้ผลแล็บอยู่แล้วไหม? ต้องการแบบใช้ cholesterol ด้วยไหม (ถ้ามีผลเลือด)? | ใช้แบบไม่ใช้ผลแล็บ | กำหนดช่องกรอกในแบบคัดกรอง (สูบบุหรี่, cholesterol) |
| 4.5 | มีแบบฟอร์มคัดกรองกระดาษที่ใช้อยู่ไหม? ขอสำเนาได้ไหม? | มี | ปรับลำดับคำถามในแอปให้ตรงกับกระดาษที่ อสม. คุ้นเคย |
| 4.6 | คำแนะนำสุขภาพที่แสดงให้ผู้ป่วย พยาบาลอยากตรวจ/แก้ถ้อยคำไหม? | อยากตรวจ | ส่งรายการคำแนะนำทั้งหมดให้ตรวจ |
| 4.7 | ผู้ที่ได้รับการวินิจฉัยแล้ว (เป็นเบาหวาน/ความดันอยู่แล้ว) ควรแสดงผลอย่างไร? ยังต้องคัดกรองซ้ำไหม? | แสดง "ป่วยแล้ว – ติดตามการรักษา" ไม่แสดงระดับเสี่ยง | ปรับการแสดงผลหลังประชุม |
| 4.8 | ค่าวิกฤตที่ต้องแจ้งด่วนนอกจากความดันสูง: น้ำตาลต่ำ < 70, ความดันต่ำ < 90/60, ชีพจรผิดปกติ — เห็นด้วยไหม? | เห็นด้วย | ปรับกฎ triage หลังประชุม |

| 5.4 | ยอมรับได้ไหมว่าข้อมูลผู้ป่วยในหมู่บ้านจะอยู่ในมือถือส่วนตัวของ อสม. (เข้ารหัส + ล็อก PIN)? | ยอมรับได้ | ถ้าไม่ได้ → ต้องใช้เครื่องของหน่วยงานเท่านั้น |
